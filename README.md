# Nexora Auth Flow Platform

A modern full-stack Next.js authentication system with OTP verification, OAuth login, email handling, and MongoDB integration.

---

## 🚀 Features

### 🔐 Authentication

* User Signup & Login
* OTP Verification System
* OAuth Login (NextAuth)
* JWT-based Authentication
* Protected Routes

---

### 📧 Email System

* Email Verification
* OTP Resend Feature
* Secure Email Flow Handling

---

### 🗄️ Database

* MongoDB Integration
* Cluster-based Connection
* Scalable Backend Architecture

---

### ⚙️ Backend Features

* Next.js API Routes
* CRUD Operations
* Delete Route Handling
* Secure Data Management

---

### 🎨 UI Features

* Responsive Design
* Carousel Component
* Dynamic Message Cards
* Modern Clean UI

---

## 🛠 Tech Stack

* Next.js
* React.js
* Node.js (API Routes)
* NextAuth
* JWT Authentication
* CSS / Tailwind

---

## 🎯 Purpose

This project demonstrates advanced full-stack development using Next.js, including authentication flows, database integration, email verification, and modern UI components.

---
